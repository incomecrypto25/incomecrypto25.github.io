Privacy policy

Application: Daily Macro Staging
Operator: Prakash
Effective date: 2 October 2026

Purpose and information accessed

This personal application uses Google account authorization to read configured Google Sheets and create, read, and verify application-authorized Google Drive files. Sheets read-only authorization can permit reading spreadsheets accessible to the authorized account; application configuration limits the resources used by the workflow. Drive access uses the drive.file scope for files created by or explicitly authorized for this application.

How information is used

Google data is used for the operator's macroeconomic research configuration, staging tests, and research artifacts. Staging connection tests read a configured test cell and upload and verify small test files. Data is not used for advertising, sold, or used to train generalized artificial intelligence or machine learning models.

Storage and service providers

OAuth credentials and refresh tokens are stored in the application's Railway environment variables. Application execution and database storage use Railway. Artifacts are stored in authorized Google Drive resources. GitHub hosts application code; this public GitHub Pages website contains only application information and this policy. Google credentials and private research data are not intended for publication on this website.

Infrastructure providers process information as necessary to operate their services. There is no public distribution of Google data by this staging application. Changes involving additional processing or sharing require an update to this policy before use.

Retention and deletion

Credentials remain configured until replaced or removed by the operator. Test artifacts and research records remain until deleted by the operator; there is no automatic retention period currently configured. Revoking authorization stops future Google access but does not automatically delete existing files or database records. The operator can delete Drive artifacts, remove stored credentials, and delete application records separately.

Access controls

Access to the Railway configuration and application database is restricted through infrastructure account permissions. Credentials must not be committed to the public website repository. The application does not collect Google passwords.

Revoking access

The operator can revoke the application's Google access at Google Account connections. For deletion or privacy questions, contact incomedumail@gmail.com.

Google API policy

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Website

This static information website has no application analytics, account forms, or application cookies. GitHub Pages may process technical request information under GitHub's own privacy policy.
