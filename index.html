Daily Macro Staging

A personal macroeconomic research application operated by Prakash. This staging environment is used to test the Daily Macro Research Engine's data connections and research workflow.

Google integration

The application reads configured Google Sheets to access research configuration and test data. It creates and reads research artifacts in Google Drive folders explicitly authorized for the application.

It requests read-only Google Sheets access and Google Drive access limited to files created by, or explicitly shared with, this application. It does not request Gmail access.

This application is for the operator's personal use. It is not a public sign-up service. This website provides application information and contains no Google account login form.

Read the privacy policy for details about Google data access, storage, and revocation.
